# Frontend documentation

The frontend is Topos's React/Vite browser application. It uses Apollo Client
and generated GraphQL operations to talk only to the federated gateway.

## Start here

1. [Quick start](getting-started/quickstart.md)
2. [Application architecture](concepts/application-architecture.md)
3. [User journeys](concepts/user-journeys.md)
4. [Testing](testing/overview.md)

## Key features

- Account signup/signin and profile editing
- Browsing, writing, editing, and viewing posts
- AI-assisted content creation and tag generation
- Peer-review queue and draft resubmission
- Search, related posts, and personalised feeds
- Grounded chat with citations
- Preview/mock mode for non-production demonstrations
